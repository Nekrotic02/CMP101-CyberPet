# CMP101-CyberPet

My first university programming assignment: a C++ console cyber-pet / Tamagotchi-style application.

This was built in first year for CMP101, within roughly four weeks of starting programming. It is kept as a historical learning artefact and shows my earliest work with C++ console input, state management, basic game logic, and an early attempt at multithreading.

## What it does

- lets the user name a pet
- tracks hunger, tiredness, and mood
- lets the user feed the pet or put it to bed
- runs background timers to reduce state values
- includes a small Eye Spy mini-game
- displays mood-dependent ASCII art

## What it demonstrates

- C++ console application basics
- menu-driven control flow
- header/source organisation
- simple state modelling
- early use of `std::thread`
- Visual Studio project structure

## Current status

This is historical first-year coursework and not an active project.

The code reflects my first steps in programming rather than my current engineering standard. It is retained to show progression from early C++ fundamentals into later security engineering and systems projects.
